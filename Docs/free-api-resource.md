# AI Provider Free / Trial API Resources

> Note: Free quotas, trial credits, available models, and rate limits can change. This page only lists official English documentation and account entry points. Always check the provider console or billing page for the current status of your own account.

## Google Gemini API

Gemini API documentation explicitly lists Free Tier and Paid Tier options. It is a practical first choice for low-cost WinSentryAI testing.

- Pricing / Free Tier: https://ai.google.dev/gemini-api/docs/pricing?hl=en
- Billing: https://ai.google.dev/gemini-api/docs/billing?hl=en
- API key: https://ai.google.dev/gemini-api/docs/api-key?hl=en
- Google AI Studio: https://aistudio.google.com/

## OpenAI API

OpenAI API usage is primarily billed through usage-based pricing and credits. Whether trial credits or specific free usage are available depends on the current account and billing status. Check the official pricing page and your Billing page before relying on free usage.

- Pricing: https://platform.openai.com/docs/pricing/
- API docs / Get started: https://platform.openai.com/docs/
- API keys: https://platform.openai.com/api-keys
- Billing overview: https://platform.openai.com/settings/organization/billing/overview
- Prepaid billing help: https://help.openai.com/en/articles/8264778-what-is-prepaid-billing

## Anthropic Claude API

Claude API keys and usage credits are managed through the Anthropic Console. Anthropic pricing information may mention small free credits for new users, but actual availability must be confirmed in Console or Billing.

- Pricing: https://docs.anthropic.com/en/docs/about-claude/pricing
- Get started: https://docs.anthropic.com/en/docs/get-started
- API overview: https://docs.anthropic.com/en/api/getting-started
- Console: https://console.anthropic.com/
- Billing / usage credits help: https://support.anthropic.com/en/articles/8977456-how-do-i-pay-for-my-api-usage
