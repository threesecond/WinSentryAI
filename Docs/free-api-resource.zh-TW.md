# AI Provider 免費 / 試用 API 資源

> 注意：AI API 的免費額度、試用 credits、可用模型與 rate limits 可能變動。本頁只整理官方英文說明頁與帳戶入口；實際可用狀態請以各 provider 後台或 billing 頁面為準。

## Google Gemini API

Gemini API 官方文件有明確列出 Free Tier / Paid Tier。適合優先作為 WinSentryAI 的低成本測試 provider。

- Pricing / Free Tier: https://ai.google.dev/gemini-api/docs/pricing?hl=en
- Billing: https://ai.google.dev/gemini-api/docs/billing?hl=en
- API key: https://ai.google.dev/gemini-api/docs/api-key?hl=en
- Google AI Studio: https://aistudio.google.com/

## OpenAI API

OpenAI API 目前主要依 usage / credits 計費。是否有 trial credits 或特定免費額度，會依帳戶與 billing 狀態而不同；使用前請確認官方 pricing 頁與你的 Billing 頁。

- Pricing: https://platform.openai.com/docs/pricing/
- API docs / Get started: https://platform.openai.com/docs/
- API keys: https://platform.openai.com/api-keys
- Billing overview: https://platform.openai.com/settings/organization/billing/overview
- Prepaid billing help: https://help.openai.com/en/articles/8264778-what-is-prepaid-billing

## Anthropic Claude API

Claude API key 與 usage credits 由 Anthropic Console 管理。Anthropic pricing 說明可能提到新使用者有少量 free credits，但實際是否可用仍需以 Console / Billing 顯示為準。

- Pricing: https://docs.anthropic.com/en/docs/about-claude/pricing
- Get started: https://docs.anthropic.com/en/docs/get-started
- API overview: https://docs.anthropic.com/en/api/getting-started
- Console: https://console.anthropic.com/
- Billing / usage credits help: https://support.anthropic.com/en/articles/8977456-how-do-i-pay-for-my-api-usage
