Summary
系統發生非正常關機，可能為電源中斷、硬體錯誤或核心崩潰（BSOD）所致。
Possible Causes
  1. 電源供應器（PSU）不穩定或突然斷電，導致系統未正常關機
  2. 記憶體（RAM）故障或過熱，觸發 Windows 保護性重啟
  3. 驅動程式衝突或核心錯誤（BugcheckCode 為 0 表示無完整 dump，可能為硬體斷電）
Recommended Actions
  1. 執行 eventvwr.msc 查看同時段是否有 Disk (51) 或 NTFS (55) 錯誤，確認磁碟健康狀態
  2. 執行 sfc /scannow 和 chkdsk C: /f /r 檢查系統檔案完整性
  3. 以 MemTest86 進行記憶體壓力測試（建議執行 2 小時以上）
  4. 檢查 Windows 小型傾印（%SystemRoot%\Minidump）是否有 .dmp 檔案
Severity
High  —  非正常關機可能造成資料遺失或磁碟損毀，需盡快排查根本原因。
